# Assignment 2 - Backend

Simple Node.js app that fetches a random user server-side and enriches data with country, exchange rates, and news.

Environment variables (copy `.env.example` to `.env`):
- `EXCHANGE_API_KEY` (required for exchange rates)
- `NEWS_API_KEY` (required for news)

Install and run:

```bash
npm install
npm start
```

Open http://localhost:3000 and click "Get Random User".
